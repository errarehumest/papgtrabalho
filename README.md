# PA & PG LAB

Gerador e analisador de Progressões Aritméticas e Geométricas.

🔗 **Teste online:** https://errarehumest.github.io/papgtrabalho/

| Arquivo | Conteúdo |
|---|---|
| `pa_pg_lab.py` | Programa em Python (menu no terminal: PA, PG e meta) |
| `test_pa_pg_lab.py` | Testes automáticos (Etapa 4) |
| `RELATORIO.md` | Planejamento, pseudocódigo, fluxograma, testes, reflexão |
| `frontend/` | Interface gráfica (HTML/CSS/JS) |

## Como executar

```powershell
# Programa no terminal
py pa_pg_lab.py

# Testes
py -m unittest test_pa_pg_lab.py -v

# Frontend: abra frontend/index.html no navegador
# ou sirva a pasta:
py -m http.server 8765 --directory frontend   # depois acesse http://localhost:8765
```
